# Interactive Visual Analytics for Explaining and Comparing Classification Models

## Architecture Layers

1. Data Layer
2. Model Layer
3. Evaluation Layer
4. Explainability Layer
5. Visual Analytics Layer
6. Service Layer
7. Dash Interface

The architecture follows a modular layered design to support model diagnosis, model improvement, and model selection tasks from the MAVIS framework.

Datasets:
- HELOC
- Bank Marketing

Models:
- Logistic Regression
- Random Forest

Explainability:
- SHAP Global Explanations
- SHAP Local Explanations
